# 투자일지 v1.78.1 테스트판

v1.78의 데이터 구조와 최종 수정 아이콘을 유지한 사용성 보완판입니다.

## 이번 수정판

- iPhone에서는 불안정한 웹 음성인식 버튼을 숨기고 키보드 받아쓰기 안내 표시
- PC 음성입력은 시작/종료 방식으로 변경하고 실행 중 세션 재사용
- 오늘의 장면에 PC 화면 캡처와 캡처 이미지 붙여넣기(Ctrl+V) 추가
- 오늘의 매매 제목 옆 용도 없는 연필 버튼 삭제
- 명언과 주식 용어의 날짜 표시 및 자정·앱 복귀 시 자동 갱신
- 투자 복기 월별 행동 변화에 지난달/이번달, 방향, 결과 문구 추가
- 다크 테마의 복기 세부 카드·패턴·원칙 영역 배경 수정
- 일지 기록에서 투자 원칙 후보를 먼저 추천하고 지킴/못 지킴/해당 없음 선택
- 좌우 스와이프에 방향성 전환 애니메이션 추가
- 상단 날짜와 모바일 기본 글자 확대
- 설정에 기본/크게/매우 크게 글자 크기 저장 기능 추가

## 데이터 호환성

기존 `journal_data` 저장 키와 일지·매매 구조를 그대로 사용합니다. 새 항목은 선택 필드로만 추가되므로 v1.77·v1.78 데이터와 백업을 불러올 수 있습니다. 테스트 전에는 설정에서 데이터 백업을 권장합니다.

HTS 캡처 자동 매매 인식은 v1.79 예정입니다.
