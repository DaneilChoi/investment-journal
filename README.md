# 투자일지 v1.9 개인 사용 완결판

매매를 방해하지 않으면서 거래 기록, 짧은 자기 복기, 주간 행동 확인과 개인 ChatGPT의 두 번째 시선을 연결하는 로컬 투자일지입니다.

## 기본 사용 흐름

1. CSV·OCR·사진 또는 직접 입력으로 거래 기록을 가져옵니다.
2. 장 마감 후 필요한 경우에만 오늘의 상태와 잘한 점·아쉬운 점을 짧게 남깁니다.
3. 토요일이나 일요일에는 다음 월요일부터의 관심 종목과 매매 계획을 기록합니다.
4. 투자 복기에서 `개인 ChatGPT로 복기`를 누르고 복사된 내용을 ChatGPT에 붙여 넣습니다.
5. 받은 JSON 결과를 앱에 붙여 넣어 사실, 놓친 연결, 다음 행동 하나를 확인합니다.

## 주간 기준

- 한 주는 토요일부터 다음 금요일까지입니다.
- 토·일요일 기록은 다음 월~금 거래주의 준비 자료로 사용됩니다.
- 거래 통계와 실현손익은 해당 거래주 금요일까지 반영합니다.
- 매매가 없는 날은 거래 평균과 행동 분석에서 제외합니다.

## AI 복기 원칙

- 서버나 API 키를 사용하지 않고 개인 ChatGPT를 엽니다.
- AI는 수익 예측이나 종목 추천을 하지 않습니다.
- 확인된 사실, 놓쳤을 가능성이 있는 연결, 다음 주 행동 하나만 요청합니다.
- 종목 뉴스는 날짜와 근거를 확인할 수 있을 때만 연결합니다.
- AI 결과는 사용자가 직접 저장·수정·삭제하고 맞음·다름을 표시할 수 있습니다.

## 데이터와 개인정보

- 모든 기록과 개인 배경 사진은 현재 브라우저 기기에 저장됩니다.
- 기존 투자일지 백업 JSON을 불러올 수 있습니다.
- 업데이트 전에는 설정에서 데이터 백업을 내려받는 것을 권장합니다.
- 서버, 회원가입, 자동 동기화 및 자동 뉴스 수집은 포함하지 않습니다.

## 설치

`investment-journal-app` 폴더를 그대로 웹 서버에 올리거나 로컬 웹 서버에서 `index.html`을 실행합니다. iPhone에서는 Safari 공유 메뉴의 `홈 화면에 추가`를 사용할 수 있습니다.
