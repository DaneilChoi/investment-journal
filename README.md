# 투자일지 v1.77

## 이번 버전
- 투자 복기 화면을 아이콘·감정 상태 중심으로 전면 개편
- 계획/원칙/충동/반복 행동을 기록 기반으로 요약
- 다음 투자에서 기억할 한 가지 행동 제안
- 오늘의 복기에 감정 선택과 사진 최대 3장 첨부
- 오늘의 투자 명언/주식 용어를 날짜 기준으로 매일 자동 변경
- AI 추천 경제 필독서와 달력 매수+매도 설명 제거
- 설정의 종목 관리 제거, 출력 버튼 단순화
- 앱 정보 팝업 추가

사진은 브라우저 저장공간을 고려해 자동 압축됩니다. 복기 코치는 현재 저장된 문장의 키워드를 이용한 로컬 기록 분석이며 매수/매도 추천 기능이 아닙니다.
