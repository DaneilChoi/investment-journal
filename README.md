# 투자일지 웹앱 v1.6

## v1.6 주요 변경
- 투자 복기 메뉴 신설: 종목 메뉴를 투자 복기로 전환
- 월간 복기 요약, 최근 복기, 반복되는 아쉬운 점, 잘한 점, 다음 계획 표시
- 매수는 빨강, 매도는 파랑으로 앱 전체 관련 UI 통일
- iPhone 터치 드래그 + ↑↓ 버튼으로 매매 순서 변경
- KOSPI/KOSDAQ 종목 검색 데이터 보강 및 온라인 전체 종목 목록 캐시
- 하이브, HPSP, 산일전기, 실리콘투 등 검색 누락 예시 보강
- 고풍스러운 황금색 앱 아이콘 적용
- 기존 자동저장, 백업/복원, 출력/PDF, 하루 1회 인트로, PWA 유지

## 실행
`index.html`을 Chrome/Edge/Safari에서 열 수 있습니다. iPhone에서 앱처럼 사용하려면 HTTPS로 배포한 뒤 Safari의 공유 메뉴에서 홈 화면에 추가하세요.

## 데이터
일지와 매매 기록은 브라우저 localStorage에 저장됩니다. 중요한 기록은 설정의 백업/내보내기로 정기적으로 저장하세요.

## 종목 검색
앱은 내장 목록을 먼저 사용하고, 인터넷 연결이 가능하면 공개 KRX 종목 목록을 가져와 브라우저에 캐시합니다. 네트워크가 없는 경우 마지막으로 캐시된 목록과 내장 목록을 사용합니다. 데이터 공급원의 갱신 시점은 KRX 실시간 데이터가 아니므로 참고용 종목 식별에 사용하세요.
