# 투자일지 v1.79.4 — v1.80 이전 최종 안정판

v1.79.3의 CSV 자동입력, 시간순 손익 계산, 균형 나침반과 국내주식 예상 거래비용 계산을 유지하면서 화면 동선과 안내 문구를 정리했습니다. 기존 저장 데이터와 최종 수정 아이콘은 그대로 유지합니다.

## v1.79.4 최종 정리

- 별도 기능이 없던 상단 점 3개 버튼을 제거하고 오늘 날짜의 실제 화면 중앙 정렬 유지
- 균형 나침반의 `반복 방지`를 의미가 분명한 `실수 반복 방지`로 변경
- 사진·카메라는 현재 선택 영역 저장 후 직접 확인하는 방식임을 입력 화면에 명확히 표시
- 영웅문4 CSV 자동입력은 현재 사용 가능하고 이미지 OCR은 v1.80 예정임을 구분
- 앱 정보와 아래 로드맵을 실제 구현 상태에 맞게 갱신
- 새로운 화면이나 모의 AI 결과를 추가하지 않고 v1.80 개발 전 안정성에 집중

## v1.79.3 예상 거래비용 반영

- 영웅문 HTS 기본 국내주식 수수료를 KRX 0.015%, NXT 0.0145%로 추정
- 화면 계산 방식에 맞춰 수수료의 10원 미만을 절사
- 2026년 일반 KRX·코스닥 국내주식 매도세를 매도금액의 0.20%로 추정
- 매수 평균단가에는 예상 매수수수료를 포함하고 매도대금에서는 예상 매도수수료와 세금을 차감
- 종목별 실현손익과 수익률, 주간 실현수익, Best·Worst 통계에 동일한 계산 적용
- 향후 실제 수수료·세금 값이 들어오면 추정치보다 실제 값을 우선하도록 데이터 구조 준비
- ETF·ETN 및 해외주식처럼 과세 방식이 다른 상품은 일반 국내주식 추정치와 다를 수 있음

## v1.79.2 화면 및 요약 수정

- 개인 표지와 겹치던 첫 화면의 `일지`, `달력에서 날짜를 선택하세요.` 문구 제거
- 달력 아래 주간 범위 제목을 카드의 가운데에 배치하고 현재 주에만 `(이번주)` 표시
- `수익률`을 `일주일 수익`으로 변경하고, 이전 날짜 매수분까지 연결한 해당 주 매도 체결의 실현손익 표시
- 원화와 달러 거래가 섞이면 각각 분리해 표시하며 수수료·세금 제외 안내 유지
- 투자복기 차트를 선택 시안과 동일한 중앙 점수·다섯 개 독립 막대·색상 끝점·주변 상태 문구의 `균형 나침반` 형태로 변경
- PC·아이폰 및 밝은·어두운 테마에서 읽기 쉬운 반응형 범례 적용

## v1.79.1 긴급 수정

- 수동 입력에 체결시간을 추가하고 새 입력에는 현재 시간을 초 단위로 자동 설정
- 과거 거래를 입력할 때 체결시간을 직접 수정 가능
- CSV와 수동 입력을 모두 날짜·체결시간·기존 입력순서로 정렬한 뒤 손익 계산
- 시간이 없는 기존 기록은 임의의 시간을 만들지 않고 `시간 미상`으로 보존
- 7일 제한 없이 모든 과거 거래를 연결하며, 종목번호를 가장 우선적인 연결 기준으로 사용
- 종목번호가 없는 기존 기록은 공백·하이픈·영문 대소문자를 정리한 종목명으로 연결 보강
- 수동 입력 화면에 6자리 종목번호 입력칸과 장기 연결 안내 추가
- CSV 가져오기 전 종목·매수/매도·수량·가격·시간을 이용해 수동 기록과 대조
- 하루 합계 수량과 가중평균가격이 맞는 수동 요약 기록도 CSV 체결 묶음과 대조
- 일치하는 수동 기록을 CSV로 교체할 수 있고 기존 매매 이유는 CSV 기록에 보존
- 자동으로 일치하지 않는 수동 기록은 삭제하지 않고 그대로 유지
- HTS 기록을 수정해도 CSV 재가져오기 방지용 원본 식별정보를 유지
- `오늘 매매 정리`에서 수동만 삭제, HTS만 삭제, 전체 삭제 제공
- 일괄 삭제 직후 `삭제 되돌리기` 제공

## v1.79 핵심 변경점

- `HTS 자료 불러오기`에서 영웅문4 `[0343]` CSV 파일을 한 개 또는 여러 개 선택
- CP949/EUC-KR 한글 CSV와 UTF-8 CSV를 자동 판별
- 두 줄로 나뉜 영웅문4 주문·체결 레코드를 한 건으로 결합
- 체결수량과 체결평균단가가 모두 있는 실제 체결만 가져오고 미체결·취소 주문 제외
- `정정주문` 표시가 있더라도 실제 체결수량이 있으면 정상 체결로 포함
- 한 주문이 여러 번 나뉘어 체결된 부분체결을 각각 보존
- 누적 CSV 여러 개를 함께 선택하거나 같은 파일을 다시 가져와도 체결번호·시간·주문번호 등을 기준으로 중복 방지
- 가져오기 전에 주문행·실제 체결·제외·새 입력 건수와 날짜·종목별 요약을 미리 확인
- 기존 수동 매매가 있는 날짜는 중복 가능성을 안내하고 기존 기록은 임의로 삭제하지 않음
- 가져온 체결에 `HTS`, 거래소(KRX/NXT), 체결시간 표시
- CSV의 실제 주문일자에 저장하고 가장 최근 가져온 날짜의 일지를 표시

## 유지된 v1.78 기능

- 매매 입력이 없는 날짜는 일지 내용은 보존하되 투자 복기와 행동 통계 계산에서 제외
- 무매매일 일지에 `매매 없음 · 복기/통계 분석에서 제외` 안내 표시
- 상단 날짜는 `9.5 금`, 일지 날짜는 `9월 5일 금`, 주간 범위는 `9.1–9.7` 형식으로 단순화
- 화면에는 짧은 날짜를 사용하고 전체 날짜는 도움말·접근성 정보와 출력물에 유지
- 사진·카메라·HTS 이미지 편집기를 선택 영역 없이 시작하도록 수정해 첫 드래그로 사각형 생성
- 선택 영역 외부 음영, 굵은 테두리와 네 모서리 조절점, 이동·크기 변경 기능 추가
- `선택 다시 하기`, `전체 이미지 사용`, `선택 영역 저장` 동작을 명확히 분리하고 아이폰 터치 대체 처리 추가
- 전날 또는 그 이전에 매수하고 다음 날 이후에 매도한 종목도 수익이 이어지도록 전체 거래를 날짜순으로 연결
- 추가 매수 시 이동평균 매입단가를 다시 계산하고, 일부 매도 시 매도 수량만 실현손익에 반영
- 종목번호와 통화를 우선 기준으로 같은 종목을 식별하고 종목번호가 없으면 종목명을 사용
- 이전 매수 기록보다 매도 수량이 많으면 임의로 수익을 만들지 않고 계산하지 못한 수량을 안내
- 투자 복기 상단을 선택한 A형 오각 방사형 차트로 변경하고 현재 균형 점수와 상태 문구 표시
- 일지 첫 화면에 개인 표지와 작은 `오늘의 나의 원칙` 표시 추가
- 설정에서 개인 표지의 일지 이름을 변경하고 기존 브라우저 데이터에 함께 저장
- iPhone에서 인쇄를 취소한 뒤 돌아오기 어려운 문제를 줄이기 위해 앱 내부 출력 미리보기와 `일지로 돌아가기` 버튼 추가
- 출력 범위의 `날짜 선택`·`이번 달` 버튼을 없애고 달력에서 하루 또는 기간을 직접 선택
- 오늘의 매매에 `사진에서 입력`, `카메라로 촬영`, `HTS 자료 불러오기`, `직접 입력` 네 가지 시작 메뉴 추가
- 사진과 카메라 이미지는 기존 사각형 자르기 화면과 오늘의 장면 저장 기능에 연결
- 통계를 월별에서 지난주·이번 주 비교 방식으로 변경
- 얼굴 위주의 행동 통계를 7일 미니 막대와 방향·상태 문구로 변경
- 월별 실현수익을 주간 참고 실현손익으로 변경
- 월 목표를 주간 수익·행동·최대손실 목표로 변경하고 주차별 저장
- 매수·매도가 모두 기록된 종목이 있을 때 이번 주 수익 Best/Worst와 과정 중심 코멘트 표시

## 계산 기준

종목별 실현손익은 모든 날짜의 매수·매도를 날짜·체결시간·기존 입력순서로 연결한 이동평균 매입단가 방식으로 계산합니다. 주간 실현손익과 Best/Worst도 같은 계산 결과 가운데 해당 주에 매도되어 실현된 손익만 사용합니다. 국내 일반주식은 v1.79.3에서 정한 예상 수수료와 매도세를 반영하며, 실제 비용 자료가 있으면 그 값을 우선합니다. ETF·ETN·해외주식 등은 과세 방식이 다를 수 있으므로 참고값입니다.

## 데이터 호환성

기존 `journal_data` 키와 일지·매매·원칙·사진·테마 데이터를 그대로 사용합니다. 거래 데이터 자체를 변경하지 않고 계산할 때 연결하므로 기존 백업도 불러올 수 있습니다. 월 목표 데이터도 삭제하지 않고 보존하며, v1.78.3부터의 주간 목표 역시 유지합니다. 테스트 전 설정에서 백업을 권장합니다.

시간이 없는 기존 수동 거래에는 시간을 임의로 부여하지 않습니다. 해당 거래는 `시간 미상`으로 표시되고 기존 입력순서를 보조 기준으로 사용하므로, 정확한 당일 손익이 필요하면 매매 수정에서 실제 체결시간과 종목번호를 입력해 주세요.

이미지 OCR, 온라인 AI, 증권사 API 연동은 이 안정판에 포함하지 않았습니다. 사진·카메라·HTS 캡처는 선택 영역을 오늘의 장면에 저장하며, 거래 자동입력은 CSV에서만 지원합니다.

## 다음 버전

다음 v1.80(v1.8)의 중심은 **온라인 AI 행동 코치와 사진·카메라 OCR**입니다.

- CSV·사진 OCR·카메라 OCR·수동 입력을 하나의 표준 거래기록으로 통합
- OCR 결과는 저장 전에 사용자가 종목·매수/매도·수량·가격·시간을 확인
- 매매 이유를 매번 적지 않아도 체결 순서·반복 매매·추격·손절·대기 패턴을 AI가 먼저 탐색
- 실제 기록과 AI의 추정을 구분하고, 애매한 판단은 한 번 누르는 확인으로 보완
- 온라인 시장 자료에는 출처를 표시하고 종목 추천보다 행동 개선에 집중
- 별도 AI 메뉴를 만들기보다 기존 개인 표지에 `이번 주 투자 이야기`와 `다음 투자에서 지킬 한 가지`를 자연스럽게 표시
- AI 키와 개인 거래기록 보호를 위해 공개 배포 전 서버 구조와 선택적 사용자 접근 방식 설계

현재 Best/Worst 코멘트는 저장된 행동 선택을 이용한 기기 내 규칙 기반 안내이며 투자 추천이 아닙니다. 해외주식·가상화폐, 실시간 증권사 API, 전체 디자인 개편은 v1.80 핵심이 안정된 뒤 검토합니다.
