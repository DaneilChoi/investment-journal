# 투자일지 웹앱 v1.0

## 실행 방법
1. `index.html`을 다운로드합니다.
2. 파일을 더블클릭하여 Chrome/Edge에서 엽니다.
3. 별도의 서버나 설치가 필요 없습니다.

## 포함 기능
- 달력에서 날짜 선택
- 날짜별 투자전 시장 분석
- 매수/매도 기록 추가/삭제
- 종목/가격/수량/매매 이유 기록
- 오늘의 복기: 잘한 점 / 아쉬운 점
- 내일의 계획
- 다음 날짜에서 어제의 계획 자동 표시
- 종목별 매매 기록
- 월간 통계 화면
- 한국어 / English 전환
- UI 클릭/선택/저장 효과음
- 설정에서 효과음 켜기/끄기
- 브라우저 localStorage 자동 저장
- JSON 데이터 백업
- 저장 데이터 초기화

## 데이터
현재 버전은 브라우저의 localStorage에 저장됩니다.
브라우저 캐시/사이트 데이터를 삭제하면 기록이 사라질 수 있으므로 설정의 `내보내기` 기능으로 주기적으로 백업하세요.
