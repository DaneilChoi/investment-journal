# 투자일지 v1.83 테스트판

## v1.83 한꺼번에 반영한 수정

- 종목별 매매구간의 상세 판단 화면을 숨겼습니다. 기존 매매기록과 AI 결과, 이전 선택값은 삭제하지 않아 데이터 호환을 유지합니다.
- 전체 투자 복기를 `잘한 점 → 고칠 점 → 다음 행동 하나` 중심으로 다시 구성했습니다. 사용자가 선택한 행동과 복기에 적은 문장에서 신호를 찾되, 근거가 부족하면 단정하지 않습니다.
- `배움과 실천 제안`에 공부할 질문, 살펴볼 사례 유형, 바로 시도할 방법을 표시합니다. 기기 내 제안은 실제 온라인 검색 결과인 것처럼 표시하지 않습니다. 개인 ChatGPT 버튼은 익명화한 주간 거래와 선택 기록을 복사해 질문하도록 돕습니다.
- 첫 페이지의 주간 수익액을 `주간 실현수익률`로 변경했습니다. 기간 내 실현손익 합계 ÷ 해당 매도분의 매입원가 합계 × 100으로 계산하고, 통화가 다르면 통화별 수익률을 따로 보여줍니다. 금액 데이터와 통계는 유지합니다.
- 제목 이모지 장식을 줄이고, 라인 아트·솔리드한 카드·파스텔 강조 배경을 사용했습니다. 글자 크기 변화보다 굵기와 색으로 위계를 표현합니다.
- 청각적 개선은 이번 버전에서 제외하고 이후 디자인 작업 항목으로 남겼습니다. 서버 배포와 온라인 AI 자동 연결은 기존 계획대로 v1.9에서 진행합니다.

## v1.82.2 복기 간소화

- 종목별 구간에서 `맞아요 / 다른 것 같아요`를 일일이 누르지 않도록 제거했습니다. 기존에 선택한 값은 데이터 호환을 위해 유지합니다.
- 개인 ChatGPT 판단을 붙여 넣으면 종목별 해석과 객관적 체결 사실을 나란히 보여줍니다. 새 결과에 체결 건수와 재진입 여부가 있으면 원자료와 교차 확인하며, 불일치하거나 수치가 없으면 검증 한계를 표시합니다.
- 자동 온라인 AI 연결은 아직 없으므로 ChatGPT 결과가 없는 구간은 `기기 내 사실`로 표시하고 매매 동기나 심리를 단정하지 않습니다.
- 복기 상단을 `한 문장 결론 → 확인된 근거 → 가능한 해석 → 다음 행동 하나`로 단순화했습니다.
- 종목별 자동 판단, 최우선 원칙, 도움 자료의 상세 영역은 한 번에 하나만 열리도록 변경했습니다. 균형 나침반과 객관적 분석은 항상 보입니다.

v1.81의 기존 저장 데이터, 사용자 아이콘, CSV·OCR 입력, 시간순 손익 계산과 균형 나침반을 유지하면서 복기 화면과 자동 행동 판단을 개선했습니다.

## v1.82 핵심 변경

### v1.82.1 확인 수정

- PC와 아이폰에서 `맞아요 / 다른 것 같아요` 선택 시 초록색·주황색 채움, 체크 표시와 반영 안내문이 나타납니다.
- 선택값은 화면 표시뿐 아니라 다음 기기 내 판단의 신뢰도와 개인 ChatGPT 복기자료에도 포함됩니다.
- 추천 원칙은 이번 주 기록이 적으면 저장된 개인 ChatGPT 판단, 이전 주 거래 판단, 기기 내 기본 제안 순으로 보완하며 출처를 표시합니다.
- 판단 근거와 균형 나침반은 접지 않고 복기 페이지에서 바로 보여줍니다.

- 종목별 매매구간은 사용자가 이유를 다시 고르지 않아도 됩니다. 거래 순서, 빠른 재진입, 손실 후 재진입, 수량 확대, 집중도를 바탕으로 기기에서 1차 판단합니다.
- 복기 첫 화면을 `30초 투자 복기`로 압축했습니다. 그림 흐름과 함께 잘한 점, 가장 중요한 반복 위험, 다음 행동 한 가지, 마음 회복 문장을 먼저 보여줍니다.
- 같은 행동이 최근 4주 중 2주 이상 나타나면 반복 패턴으로 우선 표시합니다.
- 종목별 상세 판단에는 관찰 사실과 가능한 해석을 구분하고, 사용자는 `맞아요 / 다른 것 같아요`만 선택합니다.
- 균형 나침반, 판단 근거, 원칙, 학습 자료, 개인 ChatGPT 연결은 같은 화면의 접이식 상세 영역으로 정리했습니다.
- 개인 ChatGPT에 전달하는 자료에서 종목명, 종목코드, 계좌정보, 가격, 원본 CSV와 사진을 제외합니다. 구조화된 결과를 붙여 넣으면 `내 ChatGPT 판단`으로 분명히 표시합니다.
- 기존 v1.81 및 이전 데이터, 손익 계산 방식, OCR/CSV 입력, 수정된 앱 아이콘을 그대로 유지합니다.

## 판단 방식 안내

v1.82의 기본 평가는 인터넷 AI가 만든 답이 아니라 기기 안의 규칙으로 계산한 `기기 내 1차 판단`입니다. 실제 개인 ChatGPT 결과를 사용자가 붙여 넣었을 때만 `내 ChatGPT 판단`으로 표시됩니다. 심리 상태는 사용자가 기록한 값만 활용하고, 기록이 없으면 추측으로 단정하지 않습니다.

## 다음 버전

서버 게시와 자동 온라인 AI 연결은 이번 버전에서 진행하지 않습니다. 안전한 개인 AI 연결, 사용자별 동의와 비용 확인, 자동 업데이트를 포함한 서버 배포는 **v1.9**에서 진행합니다.

## 개인 ChatGPT와 API 구분

`내 ChatGPT로 복기`는 개인정보를 뺀 복기 묶음을 복사하거나 공유한 뒤, 사용자가 로그인한 ChatGPT에서 분석하는 방식입니다. 웹앱이 ChatGPT 로그인 상태를 가로채거나 결과를 자동으로 가져오지는 않습니다.

`개인 API 정밀 복기`는 브라우저 코드에 API 키를 넣지 않도록 이번 배포판에서는 비활성화했습니다. 향후 개인 PC의 안전한 연결 프로그램이나 운영체제 보안 저장소를 사용하는 앱 형태가 준비된 뒤, 실행 직전 비용 확인과 중복 요청 방지를 포함해 연결합니다.

## OCR 테스트 주의사항

OCR 엔진과 한국어·영어 학습 데이터는 압축본에 포함되며, 사진을 서버로 올리지 않고 브라우저에서 실행합니다. 다만 현재 제공된 아이폰 촬영본은 기울기·원근·화면 무늬로 인해 문자 인식 신뢰도가 약 47%였고, 안전하게 확정할 거래 행은 추출하지 못했습니다. 이 경우 `확인 행 추가`로 인식 원문을 보며 직접 보정할 수 있습니다.

정확도 순서는 **CSV > 정면·고해상도 스크린샷 > 아이폰으로 모니터를 재촬영한 사진**으로 보는 것이 안전합니다. 계좌번호를 제외하고 표만 크게 자르고, 가능하면 정면에서 촬영하며, OCR 확인표의 수량·가격·매수/매도를 반드시 대조해 주세요.

## 행동 분석의 범위

v1.80의 행동 해석은 기기 안에서 실행되는 **규칙·계산 기반 분석**입니다. 수익이 났다고 좋은 행동, 손실이 났다고 나쁜 행동으로 단정하지 않으며, 확인된 체결·시간·사용자 심리 선택이 적으면 `관찰 중`으로 표시합니다. 현재는 외부 시장 자료를 찾아오는 온라인 AI나 종목 추천 AI가 아닙니다. 개인 거래기록과 AI 키를 보호하려면 배포 전에 서버·접근권한 구조가 먼저 필요합니다.

## 계산 기준

종목별 실현손익은 모든 날짜의 매수·매도를 날짜·체결시간·기존 입력순서로 연결한 이동평균 매입단가 방식으로 계산합니다. 주간 실현손익과 Best/Worst도 같은 계산 결과 가운데 해당 주에 매도되어 실현된 손익만 사용합니다. 국내 일반주식은 v1.79.3에서 정한 예상 수수료와 매도세를 반영하며, 실제 비용 자료가 있으면 그 값을 우선합니다. ETF·ETN·해외주식 등은 과세 방식이 다를 수 있으므로 참고값입니다.

## 데이터 호환성

기존 `journal_data` 키와 일지·매매·원칙·사진·테마 데이터를 그대로 사용합니다. 거래 데이터 자체를 변경하지 않고 계산할 때 연결하므로 기존 백업도 불러올 수 있습니다. 월 목표 데이터도 삭제하지 않고 보존하며, v1.78.3부터의 주간 목표 역시 유지합니다. 테스트 전 설정에서 백업을 권장합니다.

시간이 없는 기존 수동 거래에는 시간을 임의로 부여하지 않습니다. 해당 거래는 `시간 미상`으로 표시되고 기존 입력순서를 보조 기준으로 사용하므로, 정확한 당일 손익이 필요하면 매매 수정에서 실제 체결시간과 종목번호를 입력해 주세요.
