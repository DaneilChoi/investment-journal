# 투자일지 v1.5

간단한 주식 투자 일지 웹앱입니다. 브라우저 LocalStorage에 데이터를 저장하며 PWA 형태로 iPhone 홈 화면에 추가해 사용할 수 있습니다.

## v1.5 변경사항
- 오늘의 매매에서 **매수=빨강 / 매도=파랑**으로 UI 색상 통일
- 매수/매도 섹션별 순서 변경 유지
- PC: 마우스 드래그로 순서 변경
- iPhone/iPad: `☰` 핸들을 길게 누른 뒤 터치 드래그로 순서 변경
- 모든 기기에서 `↑ / ↓` 버튼으로도 순서 변경 가능
- KOSPI 중·소형주 및 KOSDAQ 종목 검색 보강
- 기존 온라인 검색 프록시가 실패하면 전체 KRX 종목명/코드 공개 매핑을 보조 검색원으로 사용
- 검색 결과에 시장구분을 표시하고 선택 시 종목코드를 자동 입력
- 종목 목록은 브라우저에 최대 7일 캐시하여 iPhone에서 반복 검색 시 재사용
- 기존 v1.4의 자동저장, 백업/복원, 출력/PDF, 하루 1회 인트로, PWA 설정 등을 유지

## 종목 검색 데이터에 대한 참고
KRX는 유가증권 종목기본정보와 코스닥 종목기본정보를 별도 서비스로 제공합니다. 이 앱은 브라우저에 인증키를 넣지 않기 위해 KRX 인증 API를 직접 호출하지 않고, 기존 검색 프록시와 공개 종목명/코드 매핑을 보조적으로 사용합니다. 따라서 검색 데이터는 거래소의 실시간 시세가 아니라 종목 식별용 데이터입니다.

## iPhone 사용
HTTPS로 배포한 뒤 Safari에서 열고 **공유 → 홈 화면에 추가**를 사용하세요.
