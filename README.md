# 투자일지 v1.78

v1.77 수정 아이콘 반영 버전을 기준으로 만든 테스트용 정적 PWA입니다.

## v1.78 변경점

- 복기 이모티콘 중앙 정렬과 빠른 행동 선택
- 단일 날짜/기간 달력 출력
- 투자 복기 전체 한/영 전환
- 최근 7일 하루 평균 매매 횟수
- iPhone 네 화면 좌우 스와이프
- 지원 브라우저 음성입력
- iPhone 전용 ☰ 거래 순서 이동 안정화
- 종목 검색 안내와 종목별 거래 묶어보기
- 밝은/어두운 테마 저장
- 헤더 날짜 실제 중앙 정렬
- 나의 투자 원칙 및 날짜별 지킴/못지킴 저장
- 월별 행동 변화 통계

## 데이터 호환성

기존과 동일한 `journal_data`, `journal_lang`, `journal_sound` 저장 키를 사용합니다. 기존 일지와 매매 객체는 유지하고, v1.78용 `goodActions`, `cautionActions`, `principles`만 선택적으로 추가합니다. v1.77 백업 JSON도 불러올 수 있습니다. 테스트 전에 설정에서 백업을 내보내 두는 것을 권장합니다.

## 다음 버전

HTS 캡처 자동 매매 인식은 v1.78에 포함하지 않았으며 v1.79 예정입니다.
