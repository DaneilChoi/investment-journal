# 투자일지 v1.78.2 테스트판

v1.78의 데이터 구조와 최종 수정 아이콘을 유지한 두 번째 사용성 보완판입니다.

## 이번 수정판

- 앱 자체 마이크 버튼을 제거하고 PC `Win+H`, iPhone 키보드 마이크 안내로 단순화
- 오늘의 장면에 `Win+Shift+S → Ctrl+V` 빠른 캡처 안내 추가
- 앱 화면 캡처 뒤 사각형 영역을 새로 선택하거나 이동하여 저장하는 자르기 기능 추가
- 투자 복기 행동 카드의 반복적인 “지난달보다…” 문구 제거
- 최근 복기 목록을 기록에 따른 원인·사례·오늘의 행동 중심 ‘개선 가이드’로 교체
- 통계에 월 실현수익 영역과 월 수익·행동·최대손실 목표 설정 추가
- 실현수익 데이터가 없을 때 추정 숫자를 만들지 않고 연결 준비 상태를 안내
- v1.78.1의 가독성, 다크 테마, 원칙 추천, 화면 전환 개선을 모두 유지

## 데이터 호환성

기존 `journal_data` 저장 키와 일지·매매 구조를 그대로 사용합니다. 새 항목은 선택 필드로만 추가되므로 v1.77·v1.78 데이터와 백업을 불러올 수 있습니다. 테스트 전에는 설정에서 데이터 백업을 권장합니다.

## 다음 버전

- HTS 캡처 자동 매매 인식 및 수수료·세금·부분매도를 반영한 실현수익 통계
- 서버 AI를 이용한 개인 맞춤 글·영상 추천
- 로그인·초대 승인 방식의 선별 배포와 서버 코드 보호
- 해외주식·가상화폐 자산 구분 및 환율 처리

위 항목은 데이터 연결이나 서버가 필요한 기능으로, v1.78.2에는 임의로 흉내 내지 않았습니다. HTS 캡처 자동 인식은 v1.79 예정입니다.
