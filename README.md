# 투자일지 웹앱 v1.76

## v1.76 주요 변경
- v1.6 기능 유지 및 통합
- 일지 달력: 월 좌우 스와이프
- 달력: 요일 고정 + 3주 표시, 위/아래 드래그 및 오른쪽 슬라이더로 1주씩 이동
- 마우스 휠과 ▲▼ 버튼으로도 주간 이동 가능
- 주간 요약 및 지난 주 대비 기록일/매매횟수 비교
- 하단 학습 영역: 경제 필독서(표지 이미지), 오늘의 투자 명언, 오늘의 주식 용어
- 최근 작성한 일지 목록 영역은 일지 홈에서 제외
- 매수 빨강 / 매도 파랑 색상 규칙 유지
- iPhone 매매 항목 터치 드래그 + ↑↓ 순서 변경 유지
- KOSPI/KOSDAQ 종목 검색 보강
- 황금색 노트+연필+주식차트 앱 아이콘 적용
- 자동저장, 백업/복원, 출력/PDF, 하루 1회 인트로, PWA 유지
